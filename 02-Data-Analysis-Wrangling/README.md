# 02. Data Analysis & Wrangling

This module focuses on data processing, exploratory analysis, visualization, simulation, and reporting workflows using Python.

The exercises demonstrate practical techniques commonly used in scientific computing, biotechnology, data science, and research environments to transform raw data into actionable information.

---

## 🎯 Objectives

* Process structured datasets efficiently
* Perform exploratory data analysis (EDA)
* Generate visualizations and reports
* Apply statistical and stochastic simulations
* Build reproducible data-processing workflows
* Automate common analytical tasks
