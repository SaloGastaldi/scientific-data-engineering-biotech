# 04. OOP Principles

## Overview

This section focuses on the fundamental principles of Object-Oriented Programming (OOP) in Python.

The exercises demonstrate how real-world entities can be represented as reusable software objects through encapsulation, abstraction, and class-based design. These concepts are essential for building maintainable scientific software, data analysis tools, and scalable computational workflows.

---

## 🎯 Objectives

- Understand object-oriented programming concepts
- Design reusable Python classes
- Implement attributes and methods
- Explore encapsulation and abstraction
- Develop maintainable and modular code structures
- Model real-world problems using software objects

---

## 📂 Contents

### `lote.py`

Implementation of a custom class representing inventory batches.

Concepts demonstrated:

- Class construction
- Attributes and methods
- State management
- Encapsulation of business logic

Applications:

- Inventory systems
- Scientific sample tracking
- Experimental resource management

---

### `punto.py`

Implementation of a geometric point object.

Concepts demonstrated:

- Coordinate representation
- Object manipulation
- Mathematical operations using classes

Applications:

- Scientific computing
- Geometry-based calculations
- Spatial data analysis

---

### `canguros_buenos.py`

Object-oriented implementation of a kangaroo model.

Concepts demonstrated:

- Class inheritance concepts
- Mutable object handling
- Object interaction and state management
- Debugging object behavior

Applications:

- Simulation systems
- Agent-based models
- Biological and ecological modeling
