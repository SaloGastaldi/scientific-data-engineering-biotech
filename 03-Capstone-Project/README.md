# 03. Capstone Project

## Overview

This project integrates multiple core concepts in Python programming and software engineering, including Object-Oriented Programming (OOP), memory-efficient computation, and algorithmic complexity analysis.

The implementation demonstrates how scalable and maintainable code can be designed for scientific and data-intensive applications, combining software development best practices with computational problem-solving.

---

## 🎯 Objectives

- Apply Object-Oriented Programming principles
- Implement memory-efficient data processing using generators
- Analyze algorithmic complexity and scalability
- Develop clean, reusable, and maintainable Python code
- Explore performance considerations for large datasets

---

##  📂 Contents

### `un_final.py`

Integrated project covering:

- Object-Oriented Programming (OOP)
- Custom class design
- Dunder methods (`__str__`, `__repr__`)
- Exception handling
- Generator-based iteration
- Memory optimization
- Algorithmic complexity analysis
- Computational performance considerations

Key topics explored:

#### Object-Oriented Programming

Implementation of a custom `Lote` class representing inventory batches with:

- Encapsulation of attributes and methods
- Stock management operations
- User-friendly and developer-friendly object representations

#### Memory-Efficient Processing

Implementation of a generator function using `yield` to demonstrate:

- Lazy evaluation
- Reduced memory consumption
- Efficient iteration over large datasets

#### Algorithmic Complexity

Discussion and comparison of approaches for identifying Top-K elements in large datasets, including:

- Selection-based methods
- Merge Sort complexity
- Big O analysis
- Scalability considerations
