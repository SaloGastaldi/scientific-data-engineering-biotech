Programación en Python (2021)
Este repositorio contiene el material, ejercicios y proyectos desarrollados durante la materia Programación en Python, dictada en 2021 como parte de mi formación de postgrado. 
El curso se centró en la aplicación del lenguaje para la resolución de problemas científicos, estadísticos y de ingeniería.

Objetivos del Curso
El objetivo general fue introducir los conceptos de estructura de datos, algoritmos y programación orientada a objetos (POO). Se puso especial énfasis en la capacidad de implementar métodos computacionales para enfrentar desafíos en ciencia, ingeniería y medicina.

Contenidos del Programa
El repositorio está organizado siguiendo los ejes temáticos del programa analítico: 
1- Fundamentos y Sintaxis: Diferentes entornos de programación (consola, IDE, notebooks), sintaxis del lenguaje y tipos de datos básicos. 
2- Estructuras de Control: Implementación de condicionales, iteraciones, list comprehension y recursión. 
3- Estructuras de Datos: Manejo de diccionarios, listas, tuplas, vectores y matrices.
4- Programación Orientada a Objetos (POO): Conceptos de objeto y método, además de tipos abstractos de datos como pilas, colas y árboles binarios. 
5- Análisis de Datos: Archivos de entrada/salida, cómputo de estadísticos, regresión lineal y visualización de datos.
6- Algoritmos y Complejidad: Introducción a la complejidad algorítmica y algoritmos de búsqueda y ordenamiento. 
7- Robustez de Software: Testeo y debuggeo de programas, diseño de experimentos y manejo de excepciones.

Manejo de Datos Reales
Como parte de la formación práctica en el análisis de datos, este repositorio incluye el procesamiento de datasets de gran escala. Un ejemplo destacado es el análisis del dataset de Arbolado Público Lineal (2017-2018), un archivo de más de 50MB que requirió técnicas eficientes de carga, limpieza y manipulación de datos con Python.

Herramientas y Metodología
Lenguaje: Python.
Enfoque: Teórico-práctico con resolución de ejercicios de aplicación científica. 
Proyecto Final: Incluye el archivo un_final.py, donde se integran los conocimientos de POO y análisis de datos para resolver un problema complejo.

Relevancia Profesional
Los conocimientos adquiridos en este curso son fundamentales para el desarrollo de scripts de procesamiento de datos biológicos y actúan como base para la implementación de algoritmos de Aprendizaje Automático (Machine Learning) en el ámbito de la biotecnología y la biofísica.
